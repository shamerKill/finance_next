# Task Description

# Project Overview

# Analysis
Recent AI goal runs are already available on the page. A frontend helper can identify runs generated by the "今日 AI 机会雷达" goal for the current day, then expose a compact status card with either "open today's run" or "scan today".

# Proposed Solution
Add `dailyRadarStatusFromRuns` and render a "今日雷达" section above the goal form. If today's scan exists, the card opens that run and restores the analysis. If it does not exist, it starts the existing safe daily scan and validation pipeline.
