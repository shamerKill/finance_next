# AI Paper Follow-up Workbench Link Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让历史强验证的 paper 候选主动作打开 AI Money 工作台中的原 run，而不是只打开回测详情页。

**Architecture:** 保留 follow-up item 的 `href` 指向 `/backtests/<runId>` 作为证据链接；仅把 `aiRunFollowupQueueFromRuns()` 的 `paper_candidate_validation` primaryAction href 改为 `/ai-money?runId=<goalRunId>`。无 active analysis 的 Daily Mission、Now Action、Autonomous Command 都会继承该 primaryAction href，点击后恢复 AI run 并继续进入 paper 采用/观察链路。

**Tech Stack:** Next.js client data helpers, Node.js `node:test`, TypeScript typecheck via `yarn typecheck`.

# Analysis (Populated by RESEARCH mode)
`aiRunFollowupItem()` 的 `paper_candidate_validation` item 当前 `href` 为 backtest evidence href。`aiRunFollowupQueueFromRuns()` 把该 item 的 primaryAction 也映射到同一个 href。由于 `aiDailyMissionFromState()` 和 `aiNowActionFromState()` 直接复用 follow-up primaryAction，页面主按钮最终只打开 `/backtests/<runId>`。

AI Money 前端已经支持通过 `/ai-money?runId=<id>` 恢复 run；这条路径更接近用户要的“AI 自动推进赚钱路径”，因为它能回到 paper 采用、策略保存、观察和风控复核的上下文。

# Proposed Solution (Populated by INNOVATE mode)
方案一是维持现状，主动作打开回测页；缺点是用户需要自己返回 AI Money。

方案二是把 item 和 primaryAction 都改成 AI Money run；缺点是回测证据链接丢失。

方案三是 item 继续保存回测证据 href，但 primaryAction 打开 AI Money run 工作台。采用方案三。
